# DNA 预设二：少年漫画·热血复古

> 这是 [server/dna/shonen-vintage.ts](file:///d:/26_Agent_Project/AI_comic/server/dna/shonen-vintage.ts) 的人类可读镜像。
> 适合题材：热血少年、运动竞技、少年成长、冒险、青春羁绊。

## 〇、整体气质

80-90 年代日本少年漫画的视觉气质——热血、力量感、少年气。

画风来自《SLAM DUNK》《灌篮高手》《幽游白书》《浪客剑心》《龙珠》那一档——干净利落的钢笔线稿、明显的运动速度感、明亮饱和的色彩、夸张但克制的表情与动作。

强调：热血、友情、成长、坚持、爆发、少年气、阳光、汗与泪。

画面像一部漫画连载中被高亮的一帧——读者能在这一格里"听见"呐喊或心跳。

## 一、与 New Yorker × Tomine DNA 的核心差异

| 维度 | 少年漫画·热血 | 纽约客·城市叙事 |
|---|---|---|
| 叙事节奏 | 燃点 → 反转 → 羁绊 → 再次燃起 | 观察 → 沉默 → 微妙变化 |
| 情绪表达 | 允许夸张（眉头、嘴形、汗珠、愤怒血管） | 克制（不哭不叫不瞪眼） |
| 线条 | 钢笔线 + 速度线 / 冲击线 / 集中线 | 极细 0.3mm，无速度线 |
| 色彩 | 饱和明亮（明黄、橘红、宝蓝、草绿） | 低饱和暖底（奶油、燕麦、暖白） |
| 构图 | 动态（低角度、特写、倾斜、破框） | 静态留白（25%+ 空白） |
| 对白 | 允许气泡 + 旁白 | 文字外置，对白放在正文 |
| 读者感受 | 想立刻翻到下一页 | 心里多出一个问题 |

**二者完全互斥**——选了一套就不能再选另一套。本系统不支持混搭。

## 三、人物表情规范

- 默认：强烈（眉头压低、目光集中、嘴闭合）
- 允许的大幅状态：怒吼、坚定咬牙、惊讶震惊、胜利笑容、疲惫释然、希望凝视
- 允许的微妙状态（安静场景）：自信微笑、凝视队友、安静的"我做到了"微笑
- 禁止：New Yorker 式的"内向凝视"——那属于另一个 DNA
- 太阳穴汗珠、愤怒血管、头上冲击星 = 视觉标志，**必须使用**

## 四、色调（高饱和、阳光）

- 背景天空色：明亮蔚蓝、晚霞橘红、日落品红
- 肤色：暖棕、晒红、不苍白
- 点缀色大胆使用：校服藏蓝、球衣红、训练黄、球场绿、篮球橙
- 能量亮点：白色冲击星、黄色集中线、红色愤怒血管
- 饱和。本调色板**不是低饱和**

## 五、构图（动态、冲击感）

- 低角度、荷兰角、极端前缩透视
- 运动元素带速度线 / 冲击线 / 集中线
- 反应特写（眼睛、嘴部）
- 主角镜头用低角度仰拍
- 远景保留主体主导——不要让背景吃掉主角
- 可以打破画框：动态模糊、半身、出框肢体
- 静格罕见。若用，必须是高潮前后的"刻意停顿"

## 六、文字与画面关系

- 漫画气泡、思考泡、粗体喊叫气泡、小声气泡、旁白框：**全部允许且预期**
- 拟声词作为艺术：部分、"ガッ"等手绘字符 + 冲击线
- 文字居于图中（reading-with-images 风格），不一定要走公众号正文

## 七、线条规范

钢笔线稿，**有粗细变化**——人物外轮廓可较粗（1.0-1.5mm），内部细节线较细。允许阴影交叉影线（但要规整，像网点，不画意）。整体感觉"由自信的漫画助手手绘"，**不是电脑生成**。

## 八、光影规范

高对比。太阳是一个角色。下午晚些时候的金光横扫过脸；体育馆荧光灯打出标志性的顶光；日落逆光给剪影加光晕。适度硬阴影是允许的。光应该让瞬间感觉"被压住"——读者的视线被推向主角。

## 九、叙事节奏

节奏**高**。每个面板都能装下一个转折、一拳、一个揭示、一个反转。慢面板允许，但必须是高潮前/后刻意的"暴风前"停顿。

戏剧性反讽：读者知道角色不知道的事。铺垫揭示。

对话有能量：角色讲话有信念，**不是优雅句子**。喊叫、调侃、垃圾话、立誓。内心独白允许，但要 punchy，不是意识流。

对手竞争是前景，不隐藏。主角的力量每回合都要与对手较量。

训练/准备场景用蒙太奇、重复、递进。

高潮响亮。解决是挣来的、稍微安静，但仍温暖。

灵感金句允许——但要来自角色在挣得的信念瞬间，**不是来自旁白说教**。

故事应该让读者带着能量离开，而不是一个问题。

## 十、视觉哲学

```
少年漫画的精神是"读者在最后一格里想立刻翻到下一页"。
不是"安静地把情绪留给读者慢慢品"，而是"让读者和角色一起喊出来"。

燃点 → 反转 → 羁绊 → 再次燃起，这是少年漫画的呼吸节奏。
```

## 十一、一句话定义

> **80-90 年代少年漫画的热血、速度与羁绊——让读者和角色一起燃烧，在最后一格里想立刻翻到下一页。**
