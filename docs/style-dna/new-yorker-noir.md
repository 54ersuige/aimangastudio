## 〇、整体气质

> **New Yorker 单幅叙事 × Adrian Tomine 都市写实 × 欧美独立 Graphic Novel 的文学气质。**

三者合一：

- **New Yorker 是"皮"**——色调、印刷感、单幅独立成立
- **Tomine 是"骨"**——人物克制、距离感、日常诚实
- **Graphic Novel 是"形"**——电影化镜头、留白、一格一帧

> 用一幅安静、克制、真实的画面，捕捉普通人生活中一个值得思考的瞬间。

整体气质参考 New Yorker 杂志插画、Adrian Tomine 作品、欧美独立 Graphic Novel。

强调：克制、真实、安静、细腻、留白、生活感、印刷质感。

画面像一部安静的独立电影，被切成了一组适合手机阅读的漫画镜头。

## 〇⁺、观察型幽默定位（《纽约客式单幅漫画 Style Bible V1.0》融合，2026-08-31）

- New Yorker 式的幽默是**观察型**而非**表演型**：画面平静、可信，轻微的荒诞与讽刺藏在情境本身；**笑点被读者发现，而不是被宣布**
- **像真的生活一样画，像没发生什么一样讲笑话**——人物认真地做着不合理的事情，没有人知道自己好笑
- **细节经济学**：少量准确细节 = 真实感。一个加班场景只需要"一个亮着的电脑、一杯凉咖啡、几张文件、一个疲惫的人"，不堆砌道具、不挤占人物
- **图文反差**：图负责建立情境，文字负责完成反转；文字不重复画面已经表达的东西
- 反讽保持温度，不为讽刺而讽刺，不说教——理想读者反应："这也太真实了"，然后"哈哈，但有点扎心"
- 新增禁项：儿童绘本、迪士尼式角色、皮克斯式 3D、美漫超级英雄、网络表情包、萌系（已同步 VISUAL_FORBIDDEN 与 IMAGE_NEGATIVE_PROMPT）
- 自检新增两项：`detail-economy`（细节是否少量准确而非堆砌）、`deadpan`（反讽是否全程平静、笑点藏在情境里）

## 一、画风总定义

欧美独立 Graphic Novel × 都市文艺写实 × 极简叙事插画 × 电影化镜头语言。

```
真实的人 × 真实的生活空间 × 克制的情绪 × 电影化构图 × 极简线条 × 有限色彩 × 大量留白 × 文学性叙事
```

## 二、整体审美关键词

- New Yorker 单幅叙事、杂志插画质感、印刷品质感
- 欧美文艺、独立漫画、Graphic Novel、都市生活
- 写实但不照片化
- 克制、安静、内敛、温和、微妙
- 真实、生活感、文学感、电影感、留白
- 不煽情、不说教、不刻意"可爱"、不商业插画化、不网红漫画化
- **奶油黄底 / 燕麦色 / 粉赭红棕点缀**

> "普通人的普通生活，却值得被认真观察。"

## 三、人物设计规范

### 脸部

**现代 21 世纪真实华人脸**——你在上海、北京、深圳、成都任何一家咖啡馆下午 4 点能遇到的那种。

具体要求：
- **眼睛**：小、窄、杏仁形。单眼皮或浅双都行。白眼仁几乎不外露。没有高光、没有闪亮、没有放大瞳孔、没有睫毛加重
- **眉毛**：自然，不刻意修、不粗不细
- **鼻子**：中等鼻梁，自然宽度，符合东亚面孔。不是高鼻梁、不是扁塌鼻
- **嘴**：闭合或微张，自然唇色。不亮、不涂、不厚
- **脸型**：普通。可以圆、椭圆或略方。不是 V 脸尖下巴、不是宽下颌 caricature
- **皮肤**：干净、光滑、自然肤色（暖米到浅棕，不瓷白、不蜡黄、不灰、不橄榄）。没有毛孔、没有雀斑、没有痣、没有瑕疵过度放大
- **头发**：现代剪裁。可以短发波波头、齐肩短发、男士短发。自然黑或深棕。不打理、不染色

**不在的人物**：网红脸、二次元脸、明星脸、动画角色脸

**是的人物**：地铁上你能坐旁边的、电梯里点头之交的、楼下超市收银员

### 整体设计

- 像真实的人，不是漫画角色
- 普通身材、普通五官、普通发型、普通服装
- 有轻微年龄感、有生活痕迹、不刻意美化
- **你在小区、电梯、办公室、超市里真的可能遇到的人**

## 四、人物表情规范

**情绪克制。**

**禁止**：大哭、大笑、愤怒咆哮、震惊、夸张瞪眼、夸张张嘴

**优先**：平静、若有所思、轻微皱眉、欲言又止、微妙眼神变化、面无表情、淡淡微笑、疲惫、犹豫、沉默

**真正重要的情绪隐藏在**：眼神、姿势、身体距离、停顿、构图

## 五、色调

### New Yorker 印刷感暖色调

**底色**：奶油黄、燕麦色、暖白、米色（不再是冷灰、亮蓝、纯白）

**肤色**：暖米色到浅棕（不瓷白、不蜡黄、不灰、不橄榄）

**点缀色**（克制使用）：
- 暗玫瑰
- 砖红
- 赭黄
- 深青
- 海军蓝
- 墨绿
- 胡桃棕

**禁止**：
- 冷蓝灰背景
- 霓虹色
- 糖果色
- 高饱和
- 荧光
- 品红
- 电光蓝
- 纯白

**整体感觉**：像印刷的杂志页面——暖、略去饱和、有纸质感

## 六、构图：电影化，而不是漫画化

- 远景：人物在环境中（孤独、距离、日常）
- 中景：人物和环境同在（**最常用**）
- 半身镜头：对话和关系
- 特写：谨慎使用。手、手机、食物、物品、表情、鞋、门、纸
- **空镜头**：非常重要。允许画面里没有人

**镜头不要每格都讲重点**：

```
一个人坐在那里。
两个人沉默。
爸爸看着窗外。
孩子吃东西。
电梯缓慢下降。
```

这种"什么都没发生"的镜头恰恰是本系列的重要气质。

**留白随叙事变化**（2026-08-31 对齐 Tomine）：安静的节拍用大面积空墙/桌面/窗户呼吸；生活化的室内（书架、电视墙、厨房）可以画得饱满——参考基准稿 02——但构图始终克制有序，不许挤到边缘。不做"每帧强制 25% 留白"的硬性规定。

**视线规则**（2026-08-31 对齐 Tomine）：人物**不许直视镜头**；人物之间允许自然的交谈对视（如基准稿 01 的双人对话），但情绪保持安静克制，靠姿势与视线方向传递。

## 七、线条规范

清晰、均匀、克制的墨线描边：人物与物件都有**明确可见的轮廓**，粗细一致，不粗不虚，像 0.4mm 针管笔画好后印刷在纸上。

- 不用大量漫画速度线
- 不用夸张动态线
- 不用厚重卡通描边
- 不用粗糙素描探索线

**上色**：平涂色块 + **至多一层赛璐璐阴影**（墙面、家具、衣服暗面一个更深的单色层）。禁止喷枪渐变、禁止水彩晕染。

> "经过认真观察之后画出来的，而不是电脑模板生成出来的。"

### 媒介红线：插画，不是照片（2026-08-31 增补）

玻璃幕墙、晨光反射、车流街景等"摄影感"题材会把生图模型拽进照片分布，整张输出成实景照片。因此：

- 生图 prompt 末尾强制注入【媒介约束】：手绘插画、纸面印刷质感、平涂色块、细匀墨线；纯场景格加强为"绝不能是照片"
- 负面词表（IMAGE_NEGATIVE_PROMPT）必须包含：`photograph` / `photorealistic` / `photography` / `realistic photo` / `photo background`，以及角色设定表场景下的 `watercolor` / `pencil sketch` / `faint sketchy lines` / `washed-out pale colors` / `pure white background`
- 角色设定图（2x2 sheet）prompt 最前必须有【风格锁定】段（New Yorker 单幅插画质感优先于模板词），并约束人物占面板高度 75-85%，防止"铅笔淡彩小人"

### 画风基准参考图（2026-08-31 增补，画风一致性硬锚点）

用户确认过的三张基准稿（`docs/references/`：双人咖啡店 / 过肩沉默 / 空镜咖啡细节）落盘副本放在 `server/data/style-refs/`，由 `image-store.ts 的 loadStyleReferenceImages()` 读出，**作为 reference images 注入每次生图请求**（分镜整页 / 单格重写 / 角色设定图全部链路），并在 prompt 末尾附【画风参考图】说明：只学画风（墨线描边、平涂加单层阴影、暖纸色调、构图气质），严禁把参考图中的人物与陈设画进画面。目录缺失时降级为纯文本锚定，不阻断生成。

> 教训：仅靠 prompt 文本锚定画风会随题材漂移——纯场景格被"摄影感"描述拽进照片分布，"character sheet / 2x2 grid"模板词把设定图拽向白底素描分布。确认稿参考图是唯一稳定的画风锚点。

## 八、光影规范

- 自然光：清晨、下午、阴天、室内窗光、黄昏、夜晚室内灯光
- 强烈轮廓光、巨大光束、HDR、过度戏剧化明暗、超现实光影：禁止
- 电影主光 / 戏剧化逆光 / 高对比：禁止

> 真实世界的光，不是"电影海报式的光"。柔和、漫射、无硬阴影。

## 九、文字与画面的关系（极重要）

**图片不是用来承载全部文字的。**

主要对白、旁白、心理描述和故事信息放在微信公众号正文排版里，不在图片中大量使用气泡、旁白框或解释性文字。

**画面内一律无可读文字（2026-09-02 收紧）**：手机屏幕、路牌、店铺招牌、书籍封面、包装、文件、海报一律画成无字或字迹虚化。图像模型渲染中文必然乱码——图内出现任何可读/乱码文字都视为失败输出。

**风格锁定（最高优先级，2026-09-02）**：最终画面必须是清晰均匀的墨线描边 + 平涂色块加单层赛璐璐阴影 + 暖奶油/燕麦纸色印刷质感。任何后续段落、参考图或场景描述若把画面拽向水彩、喷枪渐变、铅笔素描、动漫光泽或照片写实，一律以本风格锁定为准。

## 十、漫画的叙事节奏

**慢一点。**

不要"冲突 → 笑点 → 反转 → 金句"。

应该像文学短篇 / 独立电影：

```
观察 → 发生 → 沉默 → 微妙变化 → 留白 → 思考
```

允许没有反转、没有高潮、没有明确答案。

**让读者在结束之后心里多出一个问题。**

## 十一、情绪表达原则

> **不替读者解释情绪。**

不画"这个人很伤心"——画"这个人坐在厨房里，没有说话"。

不画"父亲很舍不得孩子"——画"父亲站在门口，看着孩子离开"。

让读者自己完成最后一步。

## 十二、特别强调：禁止"说教感"

- 教育漫画感、心灵鸡汤感、正能量宣传画、父母课堂感、道德说教：禁止
- "孩子你要懂得……"、"所以我们一定要……"：禁止

故事可以呈现真实世界的复杂性，但**不要替读者做价值判断**。

## 十三、视觉哲学

```
不是"把现实画得漂亮"——而是"认真观察现实"。
不是"制造情绪"——而是"捕捉已经存在的情绪"。
不是"告诉读者应该怎么想"——而是"给读者一个值得想一想的瞬间"。
不是"漫画人物生活在漫画世界"——而是"普通人生活在真实世界里，只不过被我们认真地记录下来"。
```

New Yorker × Tomine × Graphic Novel 三维融合：
- New Yorker 是"皮"（色调、印刷感、单幅成立）
- Tomine 是"骨"（人物克制、距离感、日常诚实）
- Graphic Novel 是"形"（电影化镜头、留白、一格一帧）

## 十五、一句话定义

> **New Yorker 单幅叙事 × Adrian Tomine 都市写实 × 欧美独立 Graphic Novel——用极简而写实的画面记录普通人的日常，用电影化镜头捕捉细微情绪，用留白代替说教，让读者自己完成故事最后的意义。**
