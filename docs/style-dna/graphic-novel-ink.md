# DNA：排线文学 Graphic Novel（graphic-novel-ink）

> ⚠ 与其他三套 DNA 互斥。系列创建后不允许切换 DNA（防风格漂移）。
> 本文件是 [server/dna/graphic-novel-ink.ts](../../server/dna/graphic-novel-ink.ts) 的人类可读镜像。

## 一句话

欧美成人写实 Graphic Novel——钢笔排线 × 4-5 色有限色板 × 都市文学。
画面的第一感受是"我在读一本严肃的欧美漫画小说"。

## 设定依据（2026-09-09 实测）

`tools/style-bakeoff.mjs` 对照实验（同场景 × 5 风格 × 2 场景）结论：
agnes-image-2.1-flash 的训练分布偏向**高信息密度写实渲染**，
「细密排线 + 有限色板」在其两个最强风格里**跨场景签名最稳、零 anime 漂移**；
细线极简（new-yorker-noir）是其短板——模型控制不住地往画面塞细节。

## 视觉定义

- **线条**：钢笔排线是画面的结构真相。线量随光变化——受光面细干笔触，阴影处交叉排线。阴影由线"砌"出来，不是深色透明图层。
- **色板（4-5 色封顶）**：暖灰（主导）、米纸黄（亮部）、墨青（阴影）、砖红（单格点缀）、橄榄/赭石（次级）。平涂但带手工印制的不均匀感。
- **人脸**：普通人，画出来而非磨出来。小而写实的眼睛、精确的皱纹笔画、可见的年龄。禁止 anime 大眼 / 星芒高光。
- **服装**：日常穿旧的——褶皱衬衫、不起眼夹克，褶皱用线表述。
- **场景**：真实当代城市场所（小公寓厨房、地铁站台、办公室走廊、傍晚街边摊）。背景用更细更轻的线，让人物浮出来。
- **光**：每帧一个明确光源（窗 / 路灯 / 顶灯），明暗靠排线密度表达。阴天与黄昏是默认情绪。
- **构图**：视线高度、中景与过肩优先、人物略偏中轴、四周留米纸色呼吸感。画面"观察"而非"表演"。

## 禁区

- anime / manga / 大眼 / 赛璐璐 / chibi / 迪士尼 / 吉卜力 / 新海诚
- 照片写实 / 3D 渲染 / CGI（负面词必须含 photograph / photorealistic，防场景词把模型拖进摄影分布）
- 水彩晕染 / 铅笔草稿 / 纯白背景模板（防 model-sheet 分布）
- 高饱和 / 糖果色 / 荧光色 / 霓虹 / 赛博朋克
- 分格多格 / 对话气泡 / 图内文字（图内只允许抽象暗示的路牌，不出现可读字母）

## 角色参考图特殊规则

- STYLE LOCK 放最前；明确 NOT a model sheet / NOT white-background sketch
- 单人全身，人物占画面高度 **75-85%**，米纸暖底 + 落影，不画家具场景
- 多视图时：同一脸型发型体型服装、共用地平线、**无标注文字**

## 叙事节拍

文学 Graphic Novel 式：观察、留白、潜台词。对白短而迂回；
内心独白每场至多一段；高潮发生在页外，页面上只留高潮后的沉默。
对白是口语化的自然中文，绝不说教、不口号化。

## 适用题材

都市情感、家庭剧、职场现实、公众号长漫。
