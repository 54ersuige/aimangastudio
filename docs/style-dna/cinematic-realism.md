# DNA 预设三：电影化写实（Cine-Photo Realism）

> 这是 [server/dna/cinematic-realism.ts](file:///d:/26_Agent_Project/AI_comic/server/dna/cinematic-realism.ts) 的人类可读镜像。
> 适合题材：现代都市、家庭剧、刑侦/律政、医疗、社会派。
> 视觉接近"电影截帧 + 电影感调色"，而非漫画笔触感。

## 〇、整体气质

电影化写实——画面的第一感受是"我从一部严肃电影里截了一帧"。

不是漫画笔触、不是插画、不是商业海报。是一种"几乎像剧照，但又经过细心构图"的视觉：

- 浅景深
- 自然光为主
- 有颗粒感的胶片质地
- 色温随剧情调冷或调暖
- 人物皮肤可见纹理与毛孔

气质参考：
- 韩国现实主义电影：李沧东（《燃烧》《薄荷糖》）、洪常秀（《这时对那时错》《独自在夜晚的海边》）
- 伊朗家庭剧：阿斯哈·法哈蒂（《一次别离》《推销员》）
- 土耳其/欧洲：努里·比格·锡兰（《冬眠》《远方》）
- 美国独立电影：肯尼斯·洛纳根（《海边的曼彻斯特》《曼哈顿》）

真实场景、真实光、真实人物，不煽情、不说教，让观众自行判断。

## 一、与另外两套 DNA 的核心差异

| 维度 | 电影化写实 | 纽约客·城市叙事 | 少年漫画·热血 |
|---|---|---|---|
| 介质感 | 胶片截帧 | 杂志插画 | 漫画钢笔线 |
| 线条 | 无勾线（光影定义边缘） | 0.3mm 极细 | 1.0-1.5mm 钢笔 |
| 皮肤 | 毛孔、细纹、血色 | 干净光滑 | 汗、污渍 |
| 光 | 窗光/路灯/室内灯（自然） | 漫射窗光 | 太阳（角色化） |
| 构图 | 视线高度，f/1.8 | 静态留白 | 低角度/特写 |
| 道具 | 真实旧物 | 静物 | 任意 |
| 服装 | 不时尚 | 普通日常 | 校服/球衣 |

**三者互斥**。

## 二、人物设计

- 真实的人，任何年龄
- 面孔**默认不漂亮**。可见毛孔、轻度细纹、偶尔斑点、眼下黑眼圈
- 80%+ 镜头眼睛看向画面外
- 头发不打理/不染色。风吹乱、睡乱、自然
- 身材普通——除非题材是运动员
- 服装不显眼，稍旧。真实颜色、真实剪裁
- **年龄可见**：50 岁不像 30 岁——有松弛、有体态、眼角变化

## 三、场景设计

- 真实场所：公寓、咖啡馆、街道、办公室、医院走廊、校门口
- 时间真实：早晨上班前、周日下午、午夜医院走廊
- 天气真实：雨、雪、阴灰、湿夏
- 空间感暗示声音：厨房噪音、远处车流、隔壁电视
- 道具是"住过的"：缺口马克杯、磨损沙发、未付账单堆、孩子画贴在冰箱上
- **没有奇幻/未来/赛博/神话**

## 四、色调

- 背景：低饱和泥土色、暖白、褪色蓝、风化木、旧瓷砖
- 肤色：自然、稍暖、稍疲惫
- 点缀色：单一暖色在冷色房间里——黄色笔记本、红马克杯、远处孩子的红外套
- 调色板感觉像电影胶片印片，**不是杂志跨页**

## 五、光影

- 默认可用光：窗光最常见
- 实用灯（台灯、屏幕）可见并自投暖光池
- 阴影柔和但真实——按物理位置投
- **没有好莱坞主光，没有戏剧逆光，没有"AI 电影逆光"**
- 观众应该相信"我能走进这个房间找到开关"

## 六、构图

- 50mm 等效镜头。需要时可微广或微紧
- 镜头在角色视线高度——不仰拍、不俯拍
- 过肩镜头（OVERT）用于对话
- 浅景深（f/1.8-f/2.8）。一平面清晰，其他自然虚化
- 手持微动——轻微 tilt、轻微 drift
- 主体常偏离中心（三分法）。负空间是真实空间
- **画框不为观众表演**。它是窗户，不是舞台

## 七、文字与画面

- 图中**几乎无文字**。现实世界的文字（路标、书脊、报纸标题、手机屏幕）允许但是偶然出现，不是主角
- **没有气泡、没有思考泡、没有旁白框**
- 所有对话、叙述、独白**在图片外的正文里**
- 图暗示声音（咖啡杯放下、雨打窗、冰箱嗡嗡声），但通过正文文字描述，不是视觉过度风格化

## 八、表情

- 默认：内向、稍疲惫、稍未完成
- 允许的微妙状态：未完成微笑、窗前长凝视、手静止在膝上、缓慢吸气
- 禁止：戏剧性泪水、剧场式愤怒、二次元式叫喊
- 角色若在大喊，镜头落在房间里其他人的反应上，不在大喊者本人
- 情绪通过：目光方向、体态、人与人之间的距离、呼吸节奏（由静态暗示）、手握物品的方式（握杯、转戒指）
- **观众不应被告知角色的感受**。观众应被留下猜测——猜测本身就是这种类型的乐趣

## 九、叙事节奏

每场有时间地点先于动作。给观众足够上下文在角色说话前先想象房间。总是用具体的物理细节（光、声、天气、道具）落地场景。

对话是**潜台词驱动**。角色没说出口的，比说出口的重要。他们回避、转移、说别的事。

允许**长段无对话动作**。一个角色可以洗衣服、喝水、叠衣服，通过这个动作观众就理解了刚才画面外发生了什么。

相机被节制提及——只在角度重新框定意义时。（如"她没有抬头。镜头留在她手上。"）

避免总结情绪。通过动作展示：角色换话题、拿起水杯、转向窗户。

**高潮在画面外或几乎不展示**。故事讲的是**余波**，不是**峰值**。峰值已经发生。

**结局未解**。观众离场后多日还在想这个角色。

对话格式遵循剧本约定：

```
角色名（居中或大写）
动作（现在时）
对话（标准引号）
```

故事应该让观众**不确定、稍不安、安静**。**不是被启发、不是被点燃、不是被说教**。

## 十、视觉哲学

```
本系列不是"画一幅好看的图"，而是"让观众相信自己看到了一帧真实电影"。
不是"制造场景感"，而是"让场景呼吸"。
不是"告诉观众应该怎么感受"，而是"把观众放进一个房间里，让感受自己发生"。
不是"角色生活在虚构漫画世界"，而是"普通人生活在真实世界里，而我们忠实地截了一帧"。

电影化写实的精神：让观众走出影院还带着那间房间的气味。
```

## 十一、一句话定义

> **从严肃当代电影里截取的一帧——胶片颗粒、自然光、真实皮肤、浅景深；观众走出影院还带着那间房间的气味。**
