# Nielsen 可用性审计（2026-09-01）

总体 7/10 良好。基础好：统一 ConfirmDialog、EmptyState 流程引导、busy 防重复点击、PageCard 展示 errorMessage、AgentWorkbench 快捷键。

## 已修复（本次）
| # | 严重度 | 问题 | 修复 |
|---|---|------|------|
| 1 | 3 | ConfirmDialog danger 模式 Enter/autoFocus 落在确认按钮，易误触删除 | [ConfirmDialog.tsx](../../src/components/ConfirmDialog.tsx)：danger 时焦点移至取消按钮、Enter 不绑定确认 |
| 2 | 3 | 确认模式不一致：章节删除是 ChapterEditor 两步确认 **之上又叠** 原生 confirm()（双重确认）；ModelConfigModal 用 window.confirm | SeriesWorkbench 删多余 confirm()（两步确认已足够）；ModelConfigModal 改为内联警示 + 二次点保存 |
| 3 | 2 | PublisherModal / ModelConfigModal 无 ESC 关闭 | 两处补 ESC 监听，与 ConfirmDialog/ManualEditors 一致 |
| 4 | 2 | 快捷键 [ ]/R 完全不可发现 | AgentWorkbench 顶栏进度条旁加常驻提示 |

## 遗留（未修，下次评估）
- 出错页面的重试入口不够显眼（PageCard 有「重新生成」但无针对 error 状态的高亮入口）
- 快捷键提示仅在 AgentWorkbench 顶栏，SeriesWorkbench 侧没有对应入口

## 经验
- 修「确认不一致」前先查清全局确认模式：本项目实际有三种（ConfirmDialog / ChapterEditor 内联两步 / 原生 confirm），正确解法是删冗余而非再套一层
