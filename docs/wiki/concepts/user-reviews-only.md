# 分镜描述是 AI 拆的，用户只做审核

> 用户 2026-10-20 的原话：**「生图的时候，自动补全需要的信息，我不自己写分镜，我只是审核分镜描述，懂吗」**

## 这条工作流

```
世界观 → 角色 → 季蓝图 → 逐话话目 → 拆分镜（每批 6 格）
                                      ↓
                          自动补全分镜描述（≥60 字）
                                      ↓
                                    出图
                                      ↓
                              ★ 用户在这里：只审核 ★
```

**用户在整个创作链路里唯一动手的地方是"审核"**——
看分镜描述对不对、看图对不对，决定要不要重画。
他**不写**分镜，也**不会**去补描述。

## 我搞反过一次

2026-10-20 上午，用户提到"出图前 AI 会改写分镜"，
我据此把补全机制改成：

- ❌ 「只补不改」——保护"用户手写的原文"。**原文是 AI 写的**，保护错了对象
- ❌ 「第 N 格描述偏短，建议你补充后重画」——**给用户派了个他根本不接的活**

用户一句"我只是审核分镜描述"就把前提纠正了。

**教训**：改机制前先确认**那个产物是谁产的**。
在 AI 参与的链路里，"我的 X"可能指用户写的，也可能指上一环节 AI 写的。
搞错对象 = 保护错东西 + 派错活，两头不讨好。

## 改成了什么

| | 改前 | 改后 |
|---|---|---|
| 补全结果不够长 | `continue` 跳过 → 该格带着短描述去出图 | **多轮重试**（最多 3 轮，每轮只处理没补够的格） |
| 补了几轮仍不够 | — | 只提示「第 N 格画面可能与剧情有出入，**审核时请留意**」 |
| 提示的语义 | — | **审核信息**，不是待办（措辞上不能出现"请你补充"） |

**为什么补不进去不能甩给用户**：带着短描述出图 → 画面失焦 →
用户审核时**看不出来画的对不对**。这是比"提示他"更糟的失败 ——
他审核的依据（描述）本身就不够。

## 判据

看到一条"请你自己补/改"的提示，先问一句：
**这个环节的产物是用户产的吗？** 不是 → 那是系统的活，不该外派。

同理，提示的措辞要分清：

- **待办**（要你动手）：只在用户真的是创作者时用
- **审核信息**（让你多看一眼）：给"只审核"的人用
